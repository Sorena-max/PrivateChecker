# PrivateChecker

یک نگهبان تلگرامی خصوصی برای سرور لینوکسی تو. با یک دستور رباتی نصب میشود که طبق زمان بندی خودت
وضعیت سرور را میفرستد، وقتی چیزی خراب شود خبرت میکند و میگوید سرور از داخل ایران در دسترس هست یا نه.

[English](README.md) | [راهنمای سریع](GUIDE.fa.md) | [Quick guide](GUIDE.md)

- گزارش کامل هر 5 تا 1200 دقیقه (پیش فرض 30)، یا با یک دکمه در همان لحظه
- هشدار برای پر شدن CPU و رم و دیسک، سرویس خراب و قطع بودن از ایران، و پیام وقتی مشکل برطرف شد
- پینگ و اتصال TCP از نود های ایرانی، با [check-host.net](https://check-host.net)
- با دکمه های ربات انتخاب میکنی گزارش شامل چه بخش هایی باشد
- ربات فقط به خودت (و کسانی که اضافه میکنی) جواب میدهد. به بقیه هیچ پاسخی نمیدهد
- بدون وابستگی: فقط کتابخانه استاندارد پایتون و یک سرویس systemd

هر نصب یعنی یک سرور، یک ربات و یک مالک. سرویس مرکزی وجود ندارد. داده ها فقط به تلگرام
(ربات خودت) و برای چک ایران به check-host.net میرود.

## نصب

یک سرور لینوکسی با systemd (دبیان، اوبونتو، فدورا، سنت او اس، راکی، آلما، اوپن سوزه یا آرچ) و دسترسی root لازم است.

1. در تلگرام [@BotFather](https://t.me/BotFather) را باز کن، `/newbot` را بفرست و توکن را کپی کن.
2. آیدی عددی خودت را از [@userinfobot](https://t.me/userinfobot) بگیر.
3. رباتی که ساختی را باز کن و Start را بزن. ربات تا تو شروع نکنی نمیتواند به تو پیام بدهد.
4. روی سرور این دستور را اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/Sorena-max/PrivateChecker/main/install.sh | sudo bash
```

نصب کننده توکن و آیدی را میپرسد و هر دو را با تلگرام چک میکند. پیش نیازهای نصب نشده
(`python3` و `curl` و `tar`) را نصب میکند و سرویس را راه میاندازد. بعد به ربات `/start` بفرست.

بدون سؤال، برای اسکریپت ها:

```bash
curl -fsSL https://raw.githubusercontent.com/Sorena-max/PrivateChecker/main/install.sh \
  | sudo bash -s -- --token 123456789:ABC... --admin 123456789 --lang fa --non-interactive
```

میخواهی اول بخوانی؟ فایل `install.sh` را دانلود کن، بخوانش و بعد `sudo bash install.sh` را بزن.
برای نصب یک نسخه مشخص به جای `main` از `--ref v0.1.0` استفاده کن.

## استفاده از ربات

با `/start` پنل باز میشود.

| دکمه | کارش |
|---|---|
| گزارش کامل همین الان | همه بخش های فعال، فوری |
| سیستم، حافظه، دیسک، شبکه ... | فقط همان بخش، همین لحظه |
| بخش های گزارش | انتخاب اینکه گزارش زمان بندی شده شامل چه چیزهایی باشد |
| فاصله ارسال گزارش | از 5 دقیقه تا 12 ساعت، مقدار دلخواه (5 تا 1200) یا توقف |
| هشدارها | روشن و خاموش کردن و آستانه CPU و رم و دیسک |
| چک ایران | هدف (پیش فرض: آی پی عمومی سرور)، پورت های TCP اضافه، چک فوری |
| سرویس های تحت نظر | یونیت های systemd که گزارش و هشدار میگیرند، مثل `nginx` یا `x-ui` |
| کاربران (فقط مالک) | افزودن و حذف افرادی که اجازهی استفاده دارند |
| زبان | فارسی یا انگلیسی |
| 🧰 PrivateToolBox (فقط مالک) | سخت سازی و بهینه سازی سرور از داخل ربات، اگر [PrivateToolBox](https://github.com/Sorena-max/PrivateToolBox) نصب باشد. با `sudo privatetoolbox integrate` فعالش کن |

دستورها: `/start` و `/report` و `/help` و `/cancel`.

گزارش شامل سیستم (توزیع، آپتایم، بار، CPU)، حافظه و سواپ، دیسک و آی نود، شبکه (ترافیک، سرعت،
آی پی عمومی، اتصال ها)، پرمصرف ترین پردازش ها، سرویس های خراب و تحت نظر، کانتینر های داکر، پورت های باز،
امنیت SSH (ورود موفق و ناموفق، پرتکرار ترین آی پی های مهاجم، نشست های فعال)، به روزرسانی های در انتظار و
چک ایران است. خط های اول گزارش میگویند همه چیز خوب است یا هشدار و مشکل داری.

هشدارها هر دقیقه بررسی میشوند. مشکل باید چند بررسی پشت سر هم ادامه داشته باشد تا خبرت کنم
(CPU سه دقیقه، رم و سرویس ها دو دقیقه، دیسک فوری). تا وقتی مشکل هست حداکثر ساعتی یک بار یادآوری میشود
و وقتی برطرف شد پیام میآید. چک ایران هر 15 دقیقه انجام میشود.

### نصب PrivateToolBox از داخل ربات

روی 🧰 PrivateToolBox بزن. اگر نصب نباشد ربات میگوید و گزینه **Install** را پیشنهاد میدهد. بعد از تایید تو، یک
helper کوچک با دسترسی root نسخه ثابت PrivateToolBox را از گیت هاب دانلود میکند، نصب میکند و به ربات وصل میکند
(ربات یک بار ری استارت میشود و وقتی آماده شد خبرت میکند). تنظیمات سرور تا وقتی پروفایلی انتخاب نکنی عوض نمیشود.

این کار به helper نیاز دارد که **به صورت پیش فرض خاموش** است. موقع نصب روشنش کن (نصب کننده میپرسد) یا هر وقت خواستی:

```bash
sudo privatechecker enable-install     # مالک بتواند PrivateToolBox را از ربات نصب کند
sudo privatechecker disable-install    # دوباره خاموش
```

helper فقط دو کار دارد (نصب نسخه ثابت و وصل کردن آن به ربات)، هیچ آرگومانی از ربات نمیگیرد و سوکتش را فقط root و
کاربر `privatechecker` میتوانند باز کنند. بدون helper دکمه دستورهایی را که باید دستی بزنی نشان میدهد.

## از روی سرور

```bash
privatechecker status      # وضعیت سرویس
privatechecker logs -f     # دنبال کردن لاگ ها
privatechecker report      # چاپ گزارش کامل در ترمینال
privatechecker doctor      # عیب یابی نصب
privatechecker update      # ارتقا با حفظ تنظیمات
privatechecker uninstall   # حذف (با --purge تنظیمات هم پاک میشود)
```

## امنیت

- فقط آیدی مالک و کاربرانی که مالک اضافه کرده میتوانند از ربات استفاده کنند. پیام بقیه نادیده گرفته میشود.
  فقط چت خصوصی پردازش میشود و گروه هرگز.
- توکن در `/var/lib/privatechecker/config.json` ذخیره میشود (دسترسی 0600 و مالک آن کاربر سرویس). توکن
  هرگز در لاگ نمیآید و از پیام های خطا حذف میشود.
- سرویس با کاربر اختصاصی `privatechecker` (بدون لاگین و بدون هوم) و سندباکس systemd اجرا میشود:
  `ProtectSystem=strict` و `ProtectHome` و `NoNewPrivileges` و `PrivateTmp` و سقف حافظه. کد در
  `/opt/privatechecker` مال root است و سرویس نمیتواند آن را تغییر دهد.
- فقط وضعیت سرور را میخواند و هرگز دستوری را که از پیام های چت برسد اجرا نمیکند.
- برای بخش SSH کاربر سرویس میتواند ژورنال و لاگ احراز هویت را بخواند (گروه های `systemd-journal` و `adm`).
  دسترسی به داکر خاموش است مگر با `--with-docker` نصب کنی. گروه docker عملاً معادل root است،
  پس فقط اگر میپذیری فعالش کن.
- اگر توکن لو رفت، به @BotFather دستور `/revoke` را بفرست، `sudo privatechecker uninstall` را بزن و
  با توکن جدید دوباره نصب کن.

## درباره چک ایران

نتیجه از نود های ایرانی [check-host.net](https://check-host.net) میآید (تهران، اصفهان، شیراز و ...).
فقط آی پی عمومی سرور (یا هدفی که تعیین کرده ای) و فهرست پورت ها برای آنها فرستاده میشود.
check-host.net تعداد شروع چک از هر آی پی را محدود میکند. PrivateChecker با ملایمت دوباره تلاش میکند
و وقتی بخواهند 10 دقیقه صبر میکند، پس گاهی گزارش ممکن است بگوید چک به خاطر محدودیت انجام نشد.
این یک همکاری رسمی نیست و check-host.net ممکن است API را تغییر دهد یا محدود کند.

## رفع اشکال

| مشکل | راهحل |
|---|---|
| ربات جواب نمیدهد | `privatechecker doctor` و بعد `privatechecker logs` را بزن. آیدیت همان آیدی مالک است؟ Start را زدی؟ |
| نصب کننده میگوید نتوانست به آیدی پیام بدهد | ربات را باز کن، Start را بزن و دوباره تلاش کن |
| "SSH logs are not readable" | توزیع تو لاگ را جای دیگری مینویسد. `privatechecker doctor` را بزن و خروجی را در یک issue بگذار |
| داکر "not accessible" میگوید | با `--with-docker` آپدیت کن |
| تلگرام روی سرور بسته است | `HTTPS_PROXY` را تنظیم کن (`systemctl edit privatechecker`) یا `api_base` را در `config.json` |

## توسعه

```bash
python3 -m unittest discover -s tests -t .
PRIVATECHECKER_HOME=/tmp/pc python3 -m privatechecker doctor
```

CI تست ها را روی پایتون 3.8 تا 3.13 اجرا میکند و سرویس واقعی را روی اوبونتو نصب میکند.
